How it works

Three passes. One honest inventory.

No accounts, no cloud sync, no setup ritual. Point Sift at your Mac and read the report.

01

Scan

Sift reads /Applications and the usual install locations, pulling bundle metadata — version, size, source, running state, last-opened date — into a single sortable list.

02

Analyze

Each app gets a plain-English identity, a 1–5 relevance score weighted by your actual usage, and a tip written for your stack — not a generic App Store blurb.

03

Decide

Keep, update, or delete — with the receipts on screen. Run it quarterly and your Applications folder never gets away from you again.
