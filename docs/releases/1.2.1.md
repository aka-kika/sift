## What it is

<!-- SF Symbol: app -->
Sift is a native macOS app that audits everything in /Applications: it explains
what each app is, scores how well it fits your workflow, tracks updates, and
keeps your license keys behind Touch ID. This is a patch release — two bug
fixes found within a day of living with 1.2.0, plus a round of detail-panel
polish.

## What shipped in 1.2.1

<!-- SF Symbol: shippingbox -->
- **Copy license key actually copies** — after authentication, the clipboard
  write could land off the main thread, where `NSPasteboard` silently does
  nothing. All license-gated actions (copy/reveal in the detail panel, the row
  context menu, the Vault) now hop back to the main actor before touching the
  pasteboard, and `LicenseKeyGuard` uses the proven completion-handler
  LocalAuthentication API with logged outcomes instead of the Swift-async path
  that misbehaves on the macOS 27 beta.
- **No more Dock ghost** — closing the window now quits the app
  (`applicationShouldTerminateAfterLastWindowClosed`), instead of leaving a
  running Dock icon with no window to reopen.
- **Cleaner utility rows** — Notes / License Key / App Link icon chips are
  flush-aligned (the Notes disclosure chevron is gone; Notes gets the same
  `+`/pencil trailing button as its siblings, and a matching "None yet"
  placeholder). Row action buttons are hidden until you hover the row, so the
  panel rests quiet and clean.

## The bug story

<!-- SF Symbol: ant -->
"Copy Key" looked like an authentication failure — but the password sheet was
fine. The real culprit: after `await`, a plain `Task {}` can resume off the
main thread, and `NSPasteboard` writes from a background thread fail without
an error. The clipboard kept whatever was in it before (`xcode-select -p`,
as it happened). One `@MainActor` annotation per call site, and four sites
later the key lands every time.
