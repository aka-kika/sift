## What this release is

Two features on top of 1.3.3, both about making the audit personal. First: per-app
notes now feed the analysis — write "I use this daily to cut release videos" on an
app, close the editor, and the re-analysis scores and recommends around how I
actually use it. Second: the detail view's utility rows became a row of small
tint-filled cubes with real pricing semantics behind them.

Beta because the cube row is new UI I want to live with for a while before calling
it done.

## Notes feed the analysis

<!-- SF Symbol: note.text -->
- **My words are evidence.** An app's Notes are injected into the prompt as the
  strongest evidence for how I use it — above URL and metadata evidence for scoring
  and best-use, but never license to invent product facts.
- **Auto re-analysis.** Closing the notes editor with changed text re-analyzes that
  app on the spot (Save ⌘↩ / Clear / Esc all count). Whitespace shuffles don't
  trigger; locked analyses never auto-run — the note waits for the next manual run.
- **Everywhere.** Notes load from the record on every analysis path: single re-runs,
  "re-analyze all," and full scans.

## Utility cubes + pricing semantics

<!-- SF Symbol: square.grid.2x2 -->
- **Six cubes, one row:** Notes · License · Subscription · Link · Lock · Favorite.
  Each is a tint-filled square with just an icon and one small badge; details live
  in tooltips and popups. Lock and Favorite are instant toggles.
- **Free is now a real mark** — the explicit opposite of Paid (setting one clears
  the other), set from the License cube's right-click menu.
- **License keys carry a type** — Lifetime / One-time / Annual / Other, set in the
  license sheet, shown as the cube's badge (even with no key saved, so it never
  drives a rule invisibly).
- **Cards gray out when they can't apply** — license & subscription for Free apps
  and My Apps, subscription also under a Lifetime/One-time license — always saying
  why in the badge, never deleting stored data.
- **License sheet grew up:** type picker plus a reveal-eye for the stored key
  (Touch ID). Copy/remove key moved to the cube's context menu.
- **Notes editor is a sheet** with Save (⌘↩), Clear, and Esc.

## Under the hood

- New `AppRecord` fields (`isFreeApp`, `licenseType`) are defaulted — lightweight
  SwiftData migration, no store surgery. **Heads-up:** once the beta touches the
  store, rolling back to 1.3.3 is untested; the fields are additive so it should
  open, but that's the one downgrade risk in here.
- Gray-out rules, Free/Paid mutual exclusion, and note-change detection are pure,
  unit-tested logic (`UtilityCardRules`, `PricingMarks`, `NotesChange`). Suite:
  90 tests, all green.
- CSV export and scoring untouched.

## Known follow-ups (why this is a beta)

- CSV's Paid column still only exports for App Store installs, even though any app
  can now be marked Paid.
- The License Vault now also lists non-App-Store paid apps — decide if that's
  wanted.
- Unranked My Apps (don't score my own builds) is designed and specced, waiting as
  the next phase.
