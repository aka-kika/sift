## What it is

<!-- SF Symbol: app -->
Sift is a native macOS app that audits everything in /Applications: what each app
is, how well it fits your workflow, update status, and what you own (license keys,
subscriptions, App Store purchases). Analysis runs on local AI — Apple Intelligence
by default. Built by **Veronica Loren** ([aka-kika](https://github.com/aka-kika)).

## The patch

<!-- SF Symbol: flag.checkered -->
Two day-after-1.3.0 fixes. The appearance switch felt laggy going Dark → System;
and on a second Mac (macOS 26, on-device only) the Apple Intelligence analysis read
poorly. Both addressed.

## What shipped in 1.3.1

<!-- SF Symbol: shippingbox -->
- **Instant appearance switching** — light/dark/system is now driven through
  AppKit (`NSApplication.appearance`) instead of SwiftUI's `.preferredColorScheme`,
  which stalled ~1s reverting Dark → System. The switch is immediate across both
  the main window and Settings.
- **Stronger on-device Apple Intelligence** — for Macs without working Private
  Cloud Compute (e.g. macOS 26), the on-device model now produces grounded,
  consistent analyses:
  - **Deterministic (greedy) sampling** for the factual scoring task instead of a
    hot temperature; same app → same score, better grounded. The rare "Use …"
    re-roll samples lightly so phrasing still varies.
  - **Permissive content guardrails** — the default guardrails silently blanked or
    degraded a large share of benign app prompts; permissive mode fixes that.
  - **Higher response-token budget** (220 → 500) so the four-field answer is never
    truncated into a "Could not parse" fallback.
  - **Retry transient failures and surface guardrail/refusal** distinctly, instead
    of silently degrading.
  - **Precise availability message** — Settings → Models → Status now names the real
    reason when the model is degraded (off / still-downloading / not-eligible).
