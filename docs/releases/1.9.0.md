## What it is

<!-- SF Symbol: app -->
Sift is a native macOS app that audits my installed apps with a local model —
what each app is, whether it earns its place in my workflow, what needs updating,
which licenses and subscriptions I pay for. The distinct thing: analysis is
grounded and local-first — evidence, not guesses, and nothing leaves the Mac by
default.

Built by **Kika** ([aka-kika](https://github.com/aka-kika)). The app I open to
decide what stays on my Mac.

## The milestone

<!-- SF Symbol: flag.checkered -->
1.9.0 is the release that closes the loop. Every version until now reached the
second Mac the slow way — download the DMG, drag it over the old copy, hope the
data carried. An app that audits everyone else's updater had no updater of its
own. Now it does, and the same day the landing page moved from a dead GitHub
Pages URL to sift.akakika.com, which is where the update feed lives.

## What shipped in 1.9.0

<!-- SF Symbol: shippingbox -->
- **Sift updates itself** — Sparkle 2 embedded, a daily check against `sift.akakika.com/appcast.xml`, the familiar Install-and-Relaunch sheet, every download verified against Sift's own EdDSA key. **Check for Updates…** in the Sift menu and on the About tab.
- **A home on the web** — sift.akakika.com, hosted on Vercel straight from `site/` in this private repo; `/Sift.dmg` always points at the current build. The License Vault got its own feature card; Developer Mode is answered in the FAQ.
- **Homebrew-ready** — a cask source at `Scripts/homebrew/sift.rb`, `auto_updates` so `brew upgrade` defers to Sparkle. Waiting on a public tap.
- **One-command release** — `Scripts/release.sh` builds, signs, notarizes, staples, regenerates the appcast, repoints the site, and bumps the cask.
- **About tab** — the GitHub row stopped apologising ("private for now" is gone).

## The story (how 1.9.0 came together)

<!-- SF Symbol: book -->
It started as a site fix. The landing page had been published from a separate
public repo because GitHub Pages will not serve a private one; that repo went
private, the page went dark, and the honest answer was to stop pretending Pages
was an option. Vercel takes a private folder without complaint, Cloudflare took a
CNAME, and sift.akakika.com was live within the hour.

Then the question that had been waiting: "we have Sparkle?" We did not. Sift could
read every other app's Sparkle feed and had never once checked its own. With a
real host for an appcast, there was no reason left. Sparkle went in as a SwiftPM
artifact, the packaging script learned to embed and sign it in the right order,
the side-build got the same treatment so it would still launch, and the tests got
an rpath so they would still load. The first copy to update itself will be on the
second Mac.
