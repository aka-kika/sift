Sift 1.12.4 fixes the ten most serious findings from the October 20 code review: safer uninstalls, keys that really stay in the Keychain, and a first run that works.

**Uninstall**
- **Mac App Store apps:** they can be uninstalled again. macOS asks once to let Sift control Finder, which moves the app for you.
- **The app goes first:** if the app itself cannot be moved to the Trash, Sift leaves its settings and data alone too.
- **Other copies:** if another copy of the app is anywhere on your Mac (Downloads, Setapp, JetBrains Toolbox), Sift finds it and leaves the shared data unchecked.
- **Homebrew:** brew uninstall is offered only for the copy Homebrew itself installed.

**Keys and privacy**
- **API keys:** cloud API keys move from the preferences file into the macOS Keychain on first launch.
- **License keys:** Sift says "Key saved" only when the Keychain really stored it. At launch it only checks whether a key exists; it reads one only after Touch ID.
- **Cloud models:** an analysis sends your app count and categories, never the names of apps you used recently or have open. Find Similar has to send your app names, so with a cloud model it asks first.

**First run and data**
- **Default model:** the default is now llama3.2, and a scan uses another installed model if that one is missing.
- **Damaged library:** Sift moves its database aside only when the file is really damaged, and tells you where it went.
- **What's new:** this window, once after each update, and from Help.

Your data and license keys carry over untouched.
