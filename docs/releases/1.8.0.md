## What it is

<!-- SF Symbol: app -->
Sift is a native macOS app that audits my installed apps with a local model —
what each app is, whether it earns its place in my workflow, what needs updating,
which licenses and subscriptions I pay for. The distinct thing: analysis is
grounded and local-first — evidence, not guesses, and nothing leaves the Mac by
default.

Built by **Kika** ([aka-kika](https://github.com/aka-kika)). The app I open to
decide what stays on my Mac.

## The milestone

<!-- SF Symbol: flag.checkered -->
1.8.0 is the first release written from inside the app. 1.7.0 shipped uninstall
and the license vault; using them for real — installing bought apps just to
capture their licences, then sweeping them away — turned up two failures that no
amount of reading the code would have surfaced. Both were the same shape: a Mac
App Store app is not like the others, and Sift assumed it was.

## What shipped in 1.8.0

<!-- SF Symbol: shippingbox -->
- **Uninstall works on App Store apps** — store bundles are `root:wheel`, and POSIX wants write permission on the *directory being renamed*, so `trashItem` refused every one of them with Cocoa 513 however writable `/Applications` is. A permission refusal is now handed to Finder, which owns that path; no password ever passes through Sift.
- **Refusals explain themselves** — the sweep used to list a bare path with the error thrown away. Each failure now carries its real reason and a Show in Finder button.
- **App Store apps can carry a licence type** — the seal used to replace the whole Key tab, so a store purchase could never be marked Lifetime. The seal is a banner above the tabs now, and every field stays; a mis-detected install can still take a key.
- **Licence types save on their own** — Save no longer requires a key, so a type can be set, corrected, or cleared at any time. A keyless licensed app reaches the vault, which it never did before.
- **Vault names link out** — the saved link first, then Sift's suggestion, then a web search. A kept licence never leaves you hunting for where you bought it.
- **A facts row closes the detail page** — on disk, last used, source, analyzed. Four cells, one line, and anything unknown is left out rather than shown blank.
- **An About tab** — icon, version, the line, and links to akakika.com, undrdr.com, X, and the repo, wearing real brand marks as bundled vector PDFs.
- **Named blocks** — "What is this?" is a heading; the two paragraphs under the score are Good for and Tip; one micro-label style throughout. No sparkles anywhere.

## The story (how 1.8.0 came together)

<!-- SF Symbol: book.closed -->
- The session started as bug reports from live use: installing bought apps to capture their licences into the vault, then uninstalling them. Both bugs were the App Store case.
- The uninstall failure was diagnosed by experiment rather than by reading — a probe binary proved `trashItem` succeeds on a writable directory and fails with Cocoa 513 on a non-writable one, then that Finder moves the same directory without complaint. The two-step fallback was tested end to end against a bundle-shaped read-only directory before it went near the app.
- The licence-type lockout came with a screenshot: an App Store app whose popover offered nothing but a subscription form. The fix put the tabs back and let the type save on its own — which then exposed a third bug nobody reported, that a keyless licensed record never reached the vault at all.
- The UI pass came last and was mostly subtraction: name every block, one caption style, four facts on one line, no sparkles.

> "i wanted to install all apps i bought and unninstall - to have the licence in vault."
> — Kika, opening the session with the workflow that found both bugs
