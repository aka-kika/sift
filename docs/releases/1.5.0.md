# Sift 1.5.0 — Grounded from your own disk, calm in the dark

*The release where Sift learned to read my project folders, point at overlap I
already own, and finally look right in dark mode.*

**Released:** 2026-07-04
**Repo:** https://github.com/aka-kika/sift (private)
**Release:** https://github.com/aka-kika/sift/releases/tag/v1.5.0

## What this release is

The big one on top of 1.4.0: two grounded features (local docs evidence,
Cross-App overlap) and a long, careful design pass on the detail panel — the
utility cubes, dark-mode color, layout, and the move to the native Mac menu bar.

## Local docs evidence

<!-- SF Symbol: doc.text -->
- Attach an app's **local project folder** and Sift reads its README (and notes
  which manifest files are present — `Package.swift`, `.xcodeproj`, `package.json`,
  …) as **primary evidence** for what the app is. This grounds analysis for my
  own apps with a private or no public repo — fully offline.
- Snapshot + remembered path: tap to attach, tap again to refresh after I edit
  the README, right-click to change/reveal/remove. Attaching, refreshing, or
  removing re-runs the analysis (and skips the run if nothing changed).

## Cross-App

<!-- SF Symbol: square.on.square -->
- A **Cross-App** cube asks the current model which of my *other installed apps*
  overlap in function with this one. Grounded by construction — the model only
  ever sees a numbered list of my apps and can only pick from it, so it can't
  invent an app or a dead link.
- It stays closed until the **whole library is analyzed** (it compares across
  every app) and is frozen along with a **locked** analysis.

## The detail panel, redesigned

<!-- SF Symbol: square.grid.3x1.below.line.grid.1x2 -->
- The utility row is now a strip of **minimal icon-only cubes** — Notes,
  License, Subscription, App Link, Lock, Favorite, Docs, plus Cross-App and a
  re-analyze chip — living in the header's right side. State is shown by icon
  and color; details live in tooltips and popups.
- **Cubes wrap to a second row** on a narrow window, and the app **title holds
  its line** instead of breaking. Content is capped to a comfortable reading
  column. The window opens at a sensible **900×620** default (resizable, min
  720×480).
- The **⋯ overflow menu is gone**: Re-analyze is a chip, Customize Description
  moved to a pencil in "What is this?", Lock is the lock cube.

## Dark mode, done right

<!-- SF Symbol: moon.stars -->
- Every cube **pastelizes** in dark mode (softened toward white) so the row
  reads as gentle pastels, not harsh saturated dots.
- The **sidebar score badges** pastelize too, with dark numerals — soft dots
  that fit the dark sidebar.
- The model-changed banner's loud orange pill became a **calm bordered button**;
  orange accents soften in dark. Light mode is unchanged throughout.

## Native Mac menu bar

<!-- SF Symbol: menubar.rectangle -->
- Filter (My Apps / Favorites) moved to the **View** menu; Rescan,
  **Re-analyze All Apps** (⇧⌘R), **Export to CSV** (⌘E), and **License Vault**
  (⇧⌘L) live in the **File** menu. The toolbar keeps just Sort and Rescan, so it
  no longer collapses into a `»` overflow at the smaller window size.

## Also new since 1.4.0's headline features

- One-click **subscription** marking (tap to flag; right-click for price and
  renewal), a **license type** picker with Touch-ID key reveal, and the App-Link
  cube's host-aware icon + suggestion dot — all carried in from the 1.4.0 work.

## Under the hood

- New `AppRecord` fields (`docsEvidence`, `docsFolderPath`) are defaulted — the
  SwiftData store migrates in place, so **all existing data carries over**:
  license keys (Keychain), notes, subscriptions, docs, My Apps, favorites. Same
  bundle ID (`com.kikaapp.appaudit`), same store.
- New pure, unit-tested logic: `DocsEvidence`, `SimilarAppsPrompt`, `FlowLayout`,
  `pastelize`, plus the prompt/threading for docs evidence and a generic
  `complete()` on all three providers. Suite: **102 tests, all green.**
- CSV export and scoring unchanged.

## Designed, deferred to a later release
