## What this release is

Three things on top of 1.3.3, all about making the audit personal and calm —
and all still local-first and evidence-only.

## Notes feed the analysis

<!-- SF Symbol: square.and.pencil -->
- An app's **Notes are evidence.** Write "I use this daily to cut release
  videos" and it becomes the strongest signal for how *I* use the app — above
  URL and metadata for scoring and best-use, but never license to invent
  product facts.
- **Auto re-analysis** when I close the notes editor with changed text (Save
  ⌘↩ / Clear / Esc). Whitespace-only edits don't trigger; locked analyses keep
  the note for the next manual run.
- Notes load on every analysis path — single re-runs, re-analyze all, full
  scans.

## Utility cubes + pricing semantics

<!-- SF Symbol: square.grid.3x1.below.line.grid.1x2 -->
- The old stacked utility rows became a **strip of icon-only cubes** — Notes,
  License, Subscription, App Link, Lock, Favorite — pinned under the header so
  they never jump when I switch apps. State is the icon + color; every detail
  lives in the tooltip.
- **Free** is now a real mark, the explicit opposite of Paid (setting one
  clears the other), from the license cube's right-click menu.
- **License type** — Lifetime / One-time / Annual / Other — set in the license
  sheet, which also reveals a stored key with Touch ID. Mac App Store apps show
  the blue verified seal.
- **One-click subscriptions**: a tap marks a subscription active with no price
  required; price, cycle, and renewal move to the right-click menu. The cube
  turns orange when a renewal is near.
- **App Link** shows a notification dot when a suggestion is ready, and once
  set uses a code glyph for source hosts (GitHub/GitLab/…) or a globe for
  websites.
- Cards **gray out when they can't apply** — license & subscription for Free
  apps and My Apps, subscription also under a Lifetime/One-time license —
  always saying why in the tooltip, never deleting stored data.

## Find similar apps you have

<!-- SF Symbol: square.on.square -->
- A **"Find similar apps you have"** button under the recommendation asks the
  current model which of my *other installed apps* overlap in function.
- **Grounded by construction.** The model only ever sees a numbered list of my
  installed apps and can only return numbers from it; the parser drops any
  number that isn't a real candidate. It cannot surface an app I don't have or
  a made-up link — the same anti-hallucination stance this edition is built on.
- Results are compact rows (icon + name + a short reason); click one to jump to
  that app.

## Under the hood

- New `AppRecord` fields (`isFreeApp`, `licenseType`) are defaulted — the
  SwiftData store migrates in place, so **all existing data carries over**:
  license keys (Keychain), notes, subscriptions, My Apps, favorites, license
  emails. Same bundle ID (`com.kikaapp.appaudit`), same store.
- New `SimilarAppsPrompt` (build + index-validating parser) and a generic
  `AnalysisService.complete(prompt:)` on all three providers.
- Pure, unit-tested logic throughout: `UtilityCardRules`, `PricingMarks`,
  `NotesChange`, `SimilarAppsPrompt`. Suite: **95 tests, all green.**
- CSV export and scoring are unchanged.

## Known follow-ups

- CSV's Paid column still exports only for App Store installs, though any app
  can now be marked Paid.
- The License Vault now also lists non-App-Store paid apps.
- Unranked My Apps (don't score my own builds) is designed and specced as the
  next phase.
