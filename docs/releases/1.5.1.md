# Sift 1.5.1 — Tidy cubes, calm rhythm, notarized

*A polish pass on 1.5.0's detail panel — a My App cube, a fixed two-row strip,
a top-down header, and an even reading rhythm. First notarized release.*

## What changed from 1.5.0

<!-- SF Symbol: hammer -->
- **My App cube.** A hammer cube in the utility strip toggles "this is a project
  I build" — and it **gates the Docs cube**: only a My App can attach a local
  project folder as evidence (the Docs cube is disabled otherwise). The hammer
  moved off the header name row into the strip (the sidebar hammer stays).
- **Fixed two-row cube grid.** The strip is now a 5-column grid — always two
  neat rows, at any window width, instead of wrapping only when narrow.
- **Top-down header.** The header reads vertically for scannability: name +
  version, then category on its own line, then bundle ID, then the update
  indicator.
- **Even reading rhythm.** The detail prose is one consistent size and font, and
  the spacing above and below the ranking dots is now equal and a touch more
  open (16pt), so the panel breathes.

## Under the hood

- Removed the now-unused `FlowLayout` (the strip is a fixed grid). Suite: **102
  tests, all green.**
- **Notarized.** This DMG is Developer ID–signed and notarized by Apple (stapled),
  so it opens without a Gatekeeper warning. Same bundle ID
  (`com.kikaapp.appaudit`), same store — all existing data carries over.

## No data or behavior changes

- Analysis, scoring, CSV export, and storage are unchanged from 1.5.0. This is a
  presentation + packaging release.
