## What it is

<!-- SF Symbol: app -->
Sift is a native macOS app that audits my installed apps with a local model —
what each app is, whether it earns its place in my workflow, what needs updating,
which licenses and subscriptions I pay for. The distinct thing: analysis is
grounded and local-first — evidence, not guesses, and nothing leaves the Mac by
default.

Built by **Kika** ([aka-kika](https://github.com/aka-kika)). The app I open to
decide what stays on my Mac.

## The milestone

<!-- SF Symbol: flag.checkered -->
1.5.1 is the first release that opens with no Gatekeeper warning — Developer ID
signed and notarized by Apple, stapled. It also closes out a long polish pass on
the detail panel that started in 1.5.0: the utility strip is finally tidy at any
window size, and the header reads top-down.

## What shipped in 1.5.1

<!-- SF Symbol: shippingbox -->
- **My App cube** — a hammer cube marks a project I build, and it gates the Docs cube: only a My App can attach a local project folder as evidence.
- **Fixed two-row cube grid** — the utility strip is a 5-column grid now, always two neat rows at any width, instead of wrapping only when narrow.
- **Top-down header** — name + version, then category on its own line, then bundle ID, then the update indicator. Scannable.
- **Even reading rhythm** — the detail prose is one size and font; the spacing above and below the ranking dots is equal and a touch more open (16pt).
- **First notarized DMG** — no more right-click-to-open.

Carried in from the 1.5.0 line: local docs evidence, Cross-App overlap, pastel
dark mode, and the move of Filter / Re-analyze All / Export / License Vault to
the native Mac menu bar.

## The story (how 1.5.1 came together)

<!-- SF Symbol: book.closed -->
- It started as "the cubes feel a bit off" and became a full design pass: shrink them, pastelize them for dark mode, pin them in the header, and finally lock them to a fixed two-row grid so they never crush the title.
- The title kept breaking into "Bloo m" on a narrow window — fixed by giving it layout priority and letting the strip wrap, then made permanent as a grid.
- Gating the Docs cube to My Apps tied the new My App cube to the local-evidence feature — mark it yours, then feed it your README.
- The final stretch: remove the now-dead FlowLayout, clean every build artifact out of the folder, and do the first real Developer ID + notarization run — Accepted on the first submit.
