Sift 1.13.1 fixes ten things found in a review of the app.

**License and keys**
- **Copy Key:** copying a license key from the License cube's right-click menu no longer opens an empty License panel. Before, pressing Save there wiped the saved email and license type.
- **API keys:** typing in the API key field in Settings and clearing it again no longer deletes your saved key. Only Remove Key does.
- **License Vault:** an app you keep for its subscription says Subscription, not Paid, and its trash button removes it.

**Updates**
- **Homebrew apps:** apps whose Homebrew cask has another name (Goose, cask block-goose) now show brew's updates. Sift reads Homebrew's own install record.
- **App Store apps:** the update check also asks your Mac's own App Store region, so an app not sold in the US store shows its updates.

**Small things**
- Locking an analysis while it is being redone no longer leaves "Analyzing" spinning.
- Cancel after `brew uninstall` no longer leaves the removed app in the list.
- "Analyzed" shows a date only after a real analysis.
- A saved link to a big file is no longer downloaded in full: Sift reads the first 128 KB.
- Re-analyze tries a link page again if it failed to load earlier.

Your data and license keys carry over untouched.
