## What it is

<!-- SF Symbol: app -->
Sift is a native macOS app that audits my installed apps with a local model —
what each app is, whether it earns its place in my workflow, what needs updating,
which licenses and subscriptions I pay for. The distinct thing: analysis is
grounded and local-first — evidence, not guesses, and nothing leaves the Mac by
default.

Built by **Kika** ([aka-kika](https://github.com/aka-kika)). The app I open to
decide what stays on my Mac.

## The milestone

<!-- SF Symbol: flag.checkered -->
Three releases in one day, and this is the one that matters: the last build
before the beta goes public. 1.9.0 gave Sift an updater, 1.10.0 gave it free
engines, and 1.11.0 is what a full audit found once we stopped adding things and
read what was there — five parallel reviews (dead code, unused files, hidden
bugs, duplicate logic, abstractions), every serious claim re-verified by hand,
then fixed in tiers with a failing test first wherever the logic allowed one.

## What shipped in 1.11.0

<!-- SF Symbol: shippingbox -->
- **Uninstall respects siblings** — removing Chrome no longer pre-checks Chrome Canary's preferences and caches. A file that belongs to another installed app is never listed.
- **brew failures are failures** — a wrong cask name or a cask that needs sudo used to read as "Homebrew finished" and hide a still-installed app.
- **No more stale-index crash** in Re-analyze when a rescan or uninstall shrinks the list mid-thought.
- **No more blank-record upsert** wiping a fresh analysis from the detail page.
- **Settings stops switching your model** behind your back; a 429 says "quota", Ollama says what Ollama said.
- **Sparkle feeds read per item** (human version over build number, beta channels ignored), checks four at a time with a 15 s cap, keys only when a real feed is configured.
- **Keychain honesty** — a plaintext license key is only removed once the Keychain verifiably holds it; the sidebar no longer reads the Keychain per row.
- **An unopenable data store is set aside, never deleted**, and the app still launches.
- **~600 lines lighter** — dead code gone, one source each for update-action copy, the score palette, the build variant, the stub record, the provider mapping, and HTTP error wording. `build_sift2.sh` is a wrapper, not a copy.
- **Docs true again** — download links point at sift.akakika.com, version strings and provider lists refreshed, executed plans archived, roadmap rewritten.

## The story (how 1.11.0 came together)

<!-- SF Symbol: book -->
"Let's run a final check before I start pushing the app to socials." Five
reviewers went through the whole repo at once; the findings that survived
re-verification were sorted into what must be fixed before strangers see it,
what should be fixed this week, and what is just weight. The first tier was
eight small, sharp fixes — the kind you only find by reading, not by using. The
second took the rough edges off the new Sparkle wiring from the same morning.
The third made the codebase lighter than it had been in months. Then one
command built, signed, notarized and published it, and the second Mac got the
update the way everyone will from now on: inside the app.
