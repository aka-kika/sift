Sift 1.12.3 keeps your license keys locked until you ask for them.

**License panel**
- Opening an app no longer reads its license key. The License panel shows "Key saved" with three buttons: Reveal, Copy and Replace.
- Reveal and Copy ask for Touch ID first. Only then does Sift read the key from the Keychain.
- After Touch ID, the panel opens again by itself, showing the key. Closing the panel hides it again.
- Replace starts from an empty field, for typing a new key.
- Changing only the email or license type leaves the saved key alone. An empty key field never deletes a key; the trash button does, behind Touch ID.

The sidebar only knows whether an app has a key, never the key itself.

Your data and license keys carry over untouched.
