## What this edition is

A personal cut of Sift, built for one Mac — mine. It keeps everything 1.3.2 added
(subscription tracking, App Store ownership/Paid markers, the purchases-ledger Vault,
instant appearance switching, the decluttered Settings) and strips out everything I
don't want, so analysis is local, evidence-only, and tuned for the best output my own
models can give.

## What changed from stock 1.3.2

<!-- SF Symbol: slider.horizontal.3 -->
- **Ollama first.** Ollama is the default and the focus. Anthropic and OpenAI stay as
  optional cloud engines under Advanced; nothing else is needed.
- **Apple Intelligence — gone.** The on-device Foundation Models engine, its Private
  Cloud Compute probe, and the whole `AppleIntelligenceService` are removed. No Apple
  model code remains.
- **No pre-built app info.** The curated `KnownApps` registry — hand-written summaries of
  common apps injected into the prompt as "authoritative facts" — is deleted. Analysis is
  grounded only in each app's own metadata, its website's fetched words, and my workflow
  profile. No catalog deciding what an app is before the model looks.
- **Tuned for best output.** Every Ollama request now carries generation options —
  `temperature 0.15`, `top_p 0.9`, `num_ctx 8192`, an output cap, and `keep_alive 30m` so
  the model stays warm across a scan. Centralized in `OllamaDefaults`.
- **Default model: `kika-ohllama:latest`** — my own model. Benchmarked against the
  installed field on this exact task: it follows the structured format reliably and reads
  well. (`qwen3.6` was rejected as the default — a pure thinking model, it spent its whole
  budget reasoning and returned an empty answer.)
- **Tolerant parser.** Strips `<think>…</think>` reasoning, accepts markdown-wrapped labels
  (`**SCORE:**`), and reads `4/5`-style scores — so any model's output still parses.

## The story

<!-- SF Symbol: book.closed -->
- Started as a personal edition off `main` (1.2.0) — then we caught it: the installed app
  was already **1.3.2**, a line that lives on tags and a `claude/*` branch but was never
  merged to `main`. Rebuilt the whole edition on 1.3.2 so nothing was lost.
- That detour solved a mystery: "without the pre build app info" meant the **KnownApps
  registry**, which 1.3.x had added to stop the small Apple model from hallucinating. With
  Apple gone and Ollama doing the work, the catalog went too.
- Notarized for the fun of it. Both the app and the DMG came back Accepted on the first try.

*Personal edition — shipped to my own /Applications.*
