## 0c5e: "no description" for App Store apps
- **Cause:** the analysis read the App Store web page, whose only description is "Download Localpage by Veronica Loren on the App Store. See screenshots, ratings and reviews…". The lookup itself worked (entity, country and universal purchase were not the problem: `itunes.apple.com/lookup?bundleId=com.akakika.localpage` returns the 1,556-character description with or without `entity=macSoftware`).
- **Fix:** `AppStoreListing` reads the listing from Apple's lookup (by store number from the link, in the link's storefront, then the Mac's region), and the prompt labels it as the App Store listing. When no storefront has it, the prompt says "Not found … do not claim the listing has no description". An App Store install with no saved link gets its listing too.
- **Proof:** `after-localpage-analysis.png`: "A read-only viewer that turns folders of HTML and Markdown files into a searchable, auto-refreshing library…", Likely useful (4). The before analysis in the VM did not finish (the 1.12.5 run in the VM answered "could not be read" with three models); Kika's own screenshot `docs/inbox/2026-10-28-appstore-description-missed.png` is the before.

## 458f: header seam and divider lines
- **Cause:** SwiftPM stamped the binary with SDK 14.0 (the deployment target), so macOS 26 drew the pre-Tahoe window: full-height sidebar, divider line, a gray toolbar band over the list.
- **Fix:** `Package.swift` passes `-platform_version macos 14.0 26.0` to the linker (`otool -l` shows `sdk 26.0`), and the window toolbar background is hidden. The sidebar floats, no vertical divider, no hairline. The sidebar is 290 to 360 points wide so Sort, Search and the sidebar button fit.
- This also turns on the macOS 26 look elsewhere (glass toolbar capsules, sheets). Checked in light and dark: `after-window-light.png`, `after-window-dark.png`, `after-star-and-notes-sheet.png`, `after-whats-new.png`.
