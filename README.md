# AppAudit

Native macOS app auditing for people who build software.

AppAudit scans installed apps, explains what each app is, ranks whether it fits your workflow, tracks updates, stores license keys, and lets you keep notes. Analysis runs locally through Ollama by default, with optional Apple Intelligence support on Macs where Foundation Models are available.

## What It Does

- Audits apps in `/Applications` and `~/Applications`
- Scores each app from 1 to 5 against your local workflow profile
- Shows one concise best-use recommendation
- Finds app updates from the App Store, Sparkle feeds, and Homebrew casks
- Suggests app links automatically, then waits for approval before using them as analysis context
- Stores license keys in macOS Keychain
- Locks analyses so they cannot be regenerated by mistake

## Requirements

- macOS 14+
- Swift 5.9+
- Ollama for the default local model provider
- `create-dmg` for polished release DMGs

```bash
brew install ollama create-dmg
ollama pull llama3.2
```

## Build

```bash
swift build
swift test
bash Scripts/make_dmg.sh
```

The release DMG is written to `AppAudit-1.0.0.dmg`.
